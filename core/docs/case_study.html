The Problem

Most "AI agent" demos hide their control flow inside a single sprawling prompt. They look impressive in a recorded clip but collapse the moment a tool fails, a model hallucinates, or cost runs away — because there is no explicit control loop, no verification, and no recovery path. AAROP demonstrates how an agent system is actually engineered at a senior / chief-architect level: the agentic loop is a first-class, inspectable state machine with bounded autonomy, self-verification, and full trace replay.

AAROP ingests an open-ended objective and drives it through a closed feedback loop — Perceive Plan Act Observe Reflect Adapt — orchestrating specialized tool-using agents, verifying its own output before committing, and emitting a structured, replayable trace for every run. It runs 100% offline via a deterministic mock model provider, while every backend (model, tools, memory) is pluggable for real deployment.

The Agentic Loop — the heart of the system

Every phase transition emits a structured trace event (phase_transition, tool_call, loop_complete), so any run is reconstructable and replayable deterministically. If a budget is exhausted, the loop escalates to a human instead of looping forever.

Engineering Rigor Demonstrated

Bounded Autonomy

Every run respects step / cost / time budgets and escalates to a human instead of looping forever.

Self-Verification

A critic agent scores each result against acceptance criteria before any commit to memory.

Resilience

Tool retries, circuit breaker, and anomaly detection in the observe phase.

Key Architecture Decisions (ADRs)

  • ADR-001 — The agentic loop is an explicit state machine, not a hidden prompt chain → enables observability, replay, and crash recovery.
  • ADR-002 — Bounded autonomy via Budget guardrails → predictable cost/latency and a safe failure mode (human escalation).
  • ADR-003 — A Verifier/Critic gate before commit → measurable error reduction over single-pass output.
  • ADR-004 — Pluggable, schema-validated tools with a circuit breaker → resilient, auditable, hot-swappable.
  • ADR-005 — Offline-first, dependency-free core → instantly runnable by reviewers; hermetic CI.

Tech Stack & Production Path

Reference core: Python (async-ready, zero runtime deps). Production reference stack documented in the repo: Temporal (durable workflows), FastAPI + Celery/Arq workers, gRPC agent-to-agent protocol, pgvector/Qdrant + cross-encoder reranker for RAG, vLLM/Ollama for self-hosted models, OpenTelemetry + Langfuse for tracing, and Docker + Kubernetes + Helm + Terraform with KEDA autoscaling.
